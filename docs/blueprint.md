# **App Name**: GeoClock

## Core Features:

- Time Display: Display the current time based on the user's location.
- Geolocation Fetch: Fetch the device's current GPS coordinates.
- Coordinate Display: Display the user's current latitude and longitude.

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for a clean and modern look.
- Secondary color: Light gray (#EEEEEE) for backgrounds.
- Accent: Teal (#009688) for interactive elements.
- Clean and readable sans-serif font for all text.
- Simple and intuitive layout with time and coordinates prominently displayed.
- Use simple, minimalist icons for location and settings.
